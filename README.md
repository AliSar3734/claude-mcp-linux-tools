# claude-mcp-linux-tools
# Linux AI Context Routing & MCP Tools

An open-source set of context-management utilities, local proxy routing configs (9router), and Model Context Protocol (MCP) integrations designed for Linux (CachyOS/Arch) power users.

## Features
- Modular MCP server integrations for local IDEs (Continue, Cursor)
- Efficient token context management and model routing for Claude 3.5 Sonnet
- Tailored for high-throughput coding and Linux system automation
